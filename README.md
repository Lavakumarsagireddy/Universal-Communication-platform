# Universal Communication

Universal Communication is a communication identity and inbox platform designed to provide users with a universal username and a unified place to manage communication across supported channels.

## Vision

Create a universal communication identity that makes it easier for people to discover, reach, and manage communication with others.

## MVP

The MVP focuses on:

- Universal username
- User profiles
- Username search
- Native 1-to-1 messaging
- Real-time message delivery
- Read and delivery status
- Push notifications
- Universal Inbox
- Android notification aggregation
- WhatsApp notification aggregation
- Telegram notification aggregation
- Privacy controls
- Blocking and reporting
